BUILT FOR THE EDITOR IN THE LOOP Promo Lab / v0.1 · Problem 01
A SMALL, ACCOUNTABLE TEAM

Story judgment meets source evidence.

  1. Master: runs a fixed workflow, tracks failures and limits calls.
  2. Source keeper: reads exact timestamps and preserves overlapping action, camera and dialogue.
  3. Hook scout: proposes up to three continuous clips per episode. Optional assembly combines a small shortlist in model mode.
  4. Story critic: compares nearby ending cuts, identifies the question left for the viewer, and checks clarity and emotional stakes.
  5. Validator + ranker: reject invented references and bad durations, score the survivors, and remove repetitive clips.

35% hook + 30% cliffhanger + 25% clarity + 10% emotion. These starting weights reflect the brief; they are not trained on ad performance.

The free baseline uses keywords and always requires human review. Connect a model through server environment variables. Every run can be exported with its trace and source evidence.

Imported material stays in memory unless you export it. Model mode sends screenplay excerpts to the configured provider. The local pack is excluded from deployment.
